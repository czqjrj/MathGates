# B11 · 知识型深度指标（最终版 v3.0）

## 一、项目完整定位回顾

### 核心原则
> **「知识体系以学习和复习知识为主，强调知识的理解，难度不应大以容易题为主，重点是通过交互动画来理解知识的形成和简单应用。」**

### 补充约束
> **「但题型方法讲解的不全面，需要大幅扩充」**

### 综合解读
- ✅ **难度门槛**: 容易题为主 → 高难度证明题占比应≤20%
- ✅ **交互优先**: 交互动画为核心教学手段 → explore/input 占比应≥50%
- ✅ **方法全面**: 题型和方法不能遗漏 → 每章应覆盖该领域主要解题方法
- ⚠️ **平衡点**: 既不是纯刷题平台，也不是纯动画演示，而是**「动画引导下的方法体系」**

## 二、修订后的深度指标（v3.0）

### 2.1 核心公式

```
depth_score_v3 = 0.30 × method_coverage + 
                 0.25 × interaction_quality + 
                 0.20 × difficulty_appropriateness +
                 0.15 × explanation_quality +
                 0.10 × non_pick_ratio
```

### 2.2 各项定义与计算

| 指标 | 权重 | 计算公式 | 目标值 | 说明 |
|-----|-----:|---------|-------:|------|
| **方法覆盖率** | 30% | `已覆盖方法数 / 该方法列表总数量` | ≥0.70 | **新增维度**，反映题型方法是否全面 |
| **交互质量** | 25% | `explore/total * 0.7 + avg_scene_complexity/20 * 0.3` | ≥0.40 | 动画探索题的核心地位 |
| **难度适宜性** | 20% | `easy_count/total - hard_count/total` (归一化到 0-1) | 0.6~0.8 | 容易题占比应显著高于难题 |
| **解答质量** | 15% | `(has_explain && has_animation_guide) / total` | ≥0.60 | explain 中应包含操作指引 |
| **非选择题比** | 10% | `(input + explore) / total` | ≥0.50 | 动手验证的比例 |

## 四、Phase 2 补强策略

### 4.1 整体方向

**不做：**
- ✗ 新增高难度证明题
- ✗ 追求复杂 multi-step 代数推导
- ✗ 抽象符号密集的题目

**必做：**
- ✓ 将现有 pick 转为 explore 类型（带滑动条/拖拽/实时反馈）
- ✓ 在 explain 中添加「如何观察」「拖动看看」的操作指引
- ✓ 为每个薄弱方法补充 1-2 道**情境化的中等难度题**
- ✓ 确保每章覆盖其方法列表中的核心方法（至少 80%）

### 4.2 Vector 章补强清单（target: method_coverage +0.3, interaction +0.15）

| 缺失方法 | 新增题建议 | 题型 | 交互方式 |
|---------|-----------|-----|---------|
| 数量积几何意义 | 「拖动 b 看 a·b 从正变负」 | explore | 滑块控制夹角 |
| 投影计算 | 「求 a 在 b 上的投影长度」 | input | 先探索后填空 |
| 垂直判定应用 | 「找与 a 垂直的所有向量」 | explore | 多点选择 + 实时校验 |
| 分点公式 | 「拖动 M 使 AM:MB = 2:3」 | explore | 比例滑块 + 动态标注 |

**实施步骤：**
1. 新增 4 道高交互题（每方法 1 道）
2. 将 5 道简单 pick 转为 input（如单位向量计算→填空题）
3. 完善所有 explain 的动画指引语

### 4.3 Statistics 章补强清单（target: method_coverage +0.35, interaction +0.12）

| 缺失方法 | 新增题建议 | 题型 | 交互方式 |
|---------|-----------|-----|---------|
| 直方图中位数估计 | 「从频率分布图估计中位数位置」 | explore | 拖动垂线分割面积 |
| 散点图相关性 | 「观察 r 随数据变化」 | explore | 移动数据点看 r 值 |
| 回归线斜率截距 | 「用最小二乘法求 b 和 a」 | input | 多步填空引导 |
| 标准差比较 | 「哪组数据更分散」 | explore | 并排显示两组分布 |

### 4.4 Counting 章补强清单（target: method_coverage +0.25, interaction +0.08）

| 缺失方法 | 新增题建议 | 题型 | 交互方式 |
|---------|-----------|-----|---------|
| 捆绑法 | 「相邻元素必须在一起有多少种排法」 | input | 分步填空 + 图示 |
| 插空法 | 「不相邻元素如何插入空隙」 | input | 拖动物品到空隙 |
| 隔板法 | 「相同物品分给不同人」 | input | 拖动隔板到小球间 |

### 4.5 Probability 章补强清单（target: method_coverage +0.3, interaction +0.1）

| 缺失方法 | 新增题建议 | 题型 | 交互方式 |
|---------|-----------|-----|---------|
| 条件概率直观 | 「已知 B 发生的情况下 A 的概率」 | explore | 筛选样本空间可视化 |
| 乘法公式应用 | 「连续两件事都发生的概率」 | input | 树状图分步填空 |
| 全概率分解 | 「三种机器生产的次品率」 | input | 加权求和步骤引导 |
| 贝叶斯逆推 | 「检验阳性真正患病的概率」 | input | prior→likelihood→posterior 三栏填空 |
