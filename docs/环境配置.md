# 环境配置要求（MathGates / 衍数阁）

本文件用于在**另一台计算机**上复现本项目的开发/构建/导出环境。
项目主体是 Godot 4 工程；额外需要一套 C++ 工具链来编译 MicroTeX 的 GDExtension（Windows 与 Android arm64）。

> 约定：下表「本机实际值」是当前开发机的路径，换机时按需替换为你自己的路径；
> 凡是路径出现在代码/配置文件里的，必须与实际一致（见「必须对齐的硬编码路径」）。

## 2. 必须对齐的硬编码路径

换机后以下几处路径/名称**必须**与你的实际安装一致，否则构建或运行会失败：

| 位置 | 内容 | 说明 |
|---|---|---|
| `gdextension/CMakeLists.txt` | `C:/msys64/mingw64/lib/lib*.a`（Windows 静态链） | MinGW-w64 静态库路径，随 MSYS2 安装位置变化 |
| `gdextension/CMakeLists.txt` | `MT_ANDROID_PREFIX=.../third_party/android_deps/install/arm64` | 预编译 freetype/tinyxml2（arm64） |
| Android 构建命令行 | `-DCMAKE_TOOLCHAIN_FILE=<NDK>/build/cmake/android.toolchain.cmake` | NDK 版本/路径 |
| `export_presets.cfg` | `export_path="build/衍数阁.apk"` 等 | 导出产物路径 |
| Godot 编辑器设置 | `export/android/android_sdk_path`、`java_sdk_path` | 见第 6 节 |
| `.gdextension` | `res://gdextension/bin/...` | 扩展产物路径，随构建输出 |

## 3. 安装基础工具链（MSYS2 + MinGW-w64 msvcrt）

1. 安装 MSYS2 到 `C:\msys64`（默认即可）。
2. （可选，网络受限时）把 pacman 镜像切到国内，例如南京大学镜像：
   编辑 `C:\msys64\etc\pacman.d\mirrorlist.mingw64`（及 `mirrorlist.msys`），把 `mirror.nju.edu.cn` 的条目置顶。
3. 打开 **MSYS2 MinGW 64-bit** 终端，更新并安装：
   ```bash
   pacman -Syu
   pacman -S --needed \
     mingw-w64-x86_64-gcc \
     mingw-w64-x86_64-cmake \
     mingw-w64-x86_64-ninja \
     mingw-w64-x86_64-pkgconf \
     mingw-w64-x86_64-freetype \
     mingw-w64-x86_64-harfbuzz \
     mingw-w64-x86_64-tinyxml2
   ```
   本项目实测版本：gcc 16.2.0、cmake 4.4.4、ninja 1.13.2、freetype 2.14.3、tinyxml2 11.0.0、harfbuzz 14.6.0。
4. 校验（不必污染全局 PATH，用完整路径调用即可）：
   ```powershell
   & "C:\msys64\mingw64\bin\gcc.exe" --version
   & "C:\msys64\mingw64\bin\cmake.exe" --version
   & "C:\msys64\mingw64\bin\ninja.exe" --version
   ```
   构建时把 `C:\msys64\mingw64\bin` 与 `C:\msys64\usr\bin` 临时加到 PATH（pkg-config 需要）。

> 必须有 **msvcrt** 运行时（mingw64 子系统），**不要**用 ucrt，否则与 godot-cpp/MicroTeX 混用会链接失败或运行期崩溃。

## 4. Godot 引擎与导出模板

1. 下载并解压 **Godot 4.4.1 stable**（标准版，非 .NET）：用于构建/运行扩展、跑回归脚本，与 godot-cpp 4.4 严格对齐。
2. 下载并解压 **Godot 4.7.2 stable**：用于编辑器与导出（本机导出即用它）。
3. 安装 **4.7.2 的导出模板**：编辑器菜单「编辑器 → 管理导出模板 → 从文件安装」，或用命令行：
   ```powershell
   & "<godot472.exe>" --headless --install-export-templates "<Godot_v4.7.2-stable_export_templates.tpz>"
   ```
   安装后应存在 `%APPDATA%\Godot\export_templates\4.7.2.stable\`，其中包含 `android_debug.apk`。

> 说明：`project.godot` 的 `config/features=("4.4","GL Compatibility")`。用 4.7.2 打开会有「版本较旧」提示，属正常。

## 5. Android 工具（SDK / JDK / NDK）

1. 安装 **Android SDK** 到 `C:\Android\Sdk`，确保有以下组件（可用 `sdkmanager` 安装）：
   - `platform-tools`（含 `adb`，本机 adb 1.0.41）
   - `build-tools;36.0.0`（本机同时有 `35.0.0`）
   - `platforms;android-35`、`platforms;android-36`（本机两者均有）
   - `cmdline-tools;latest`
2. 安装 **JDK 17** 到 `C:\Android\jdk17`（OpenJDK 17）。
3. 安装 **Android NDK 23.2.8568313**（本机在 `D:\Android\Sdk\ndk\23.2.8568313`；也可放到 `C:\Android\Sdk\ndk`，但需与构建命令里的 toolchain 路径一致）。
4. 真机调试需 `adb`（`platform-tools`）。小米/MIUI 设备若要脚本注入点击，需额外开启「USB 调试(安全设置)」。

## 6. Godot 编辑器设置（Windows 端一次性）

在 Godot 编辑器中「编辑器 → 编辑器设置」或直接编辑
`%APPDATA%\Godot\editor_settings-4.7.tres`：

```
export/android/android_sdk_path = "C:/Android/Sdk"
export/android/java_sdk_path    = "C:/Android/jdk17"
export/android/debug_keystore    = "<你的 debug.keystore>"
export/android/debug_keystore_pass = "android"
```

导出预设 `export_presets.cfg` 已随仓库提供，关键项：
- `gradle_build/use_gradle_build=false`（离线打包，不走 gradle）
- `gradle_build/compress_native_libraries=false`
- `include_filter="gdextension/res.bin"`（把运行时资源打进包）
- `exclude_filter` 排除 `third_party/*`、`gdextension/build*`、`tests/mathtex_test/*` 等

## 7. 获取源码与依赖

```powershell
git clone <repo> MathGates
cd MathGates
```

仓库已包含：
- `gdextension/src/`（扩展 C++ 源码）、`gdextension/res/`（MicroTeX 资源）、`gdextension/res.bin`（资源包，导出用）
- 根目录 `math_tex.gdextension`、`export_presets.cfg`

**不入库**、需要本机放置的依赖（放到 `third_party/`，该目录已在 `.gitignore`）：

```powershell
cd third_party

# godot-cpp（4.4 分支，务必对齐）
git clone -b 4.4 https://github.com/godotengine/godot-cpp.git
# 期望 commit: b0e3b1e

# MicroTeX
git clone https://github.com/NanoMichael/MicroTeX.git
# 期望 commit: 0e3707f
```

另外需要**预编译的 arm64 静态依赖** `third_party/android_deps/install/arm64/{lib,include}`：
- `libfreetype.a`、`libtinyxml2.a` 及头文件（用 NDK 交叉编译 freetype 2.13.3 / tinyxml2 10.0.0 得到；本机源码在 `third_party/android_deps/src/`，构建在 `.../build/`）。

## 8. 构建扩展

> 每次构建前：`$env:PATH = "C:\msys64\mingw64\bin;C:\msys64\usr\bin;" + $env:PATH`
> `gdextension/CMakeLists.txt` 会在配置时自动为 `third_party/`、`gdextension/build*` 写入 `.gdignore`（防止第三方源码被打进导出包）。

### 8.1 Windows（Debug，编辑器/本地运行用）

```powershell
& "C:\msys64\mingw64\bin\cmake.exe" -G Ninja -S gdextension -B gdextension/build `
  -DCMAKE_BUILD_TYPE=Debug `
  -DCMAKE_C_COMPILER=C:/msys64/mingw64/bin/cc.exe `
  -DCMAKE_CXX_COMPILER=C:/msys64/mingw64/bin/c++.exe `
  -DCMAKE_MAKE_PROGRAM=C:/msys64/mingw64/bin/ninja.exe
& "C:\msys64\mingw64\bin\ninja.exe" -C gdextension/build
```

产物：`gdextension/bin/godot_math_tex.windows.debug.x86_64.dll`（全静态链接，仅依赖系统 DLL）。

### 8.2 Android arm64（Release）

```powershell
& "C:\msys64\mingw64\bin\cmake.exe" -G Ninja -S gdextension -B gdextension/build-android `
  -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_TOOLCHAIN_FILE=D:/Android/Sdk/ndk/23.2.8568313/build/cmake/android.toolchain.cmake `
  -DANDROID_ABI=arm64-v8a `
  -DANDROID_PLATFORM=android-21 `
  -DCMAKE_MAKE_PROGRAM=C:/msys64/mingw64/bin/ninja.exe
& "C:\msys64\mingw64\bin\ninja.exe" -C gdextension/build-android
```

产物：`gdextension/bin/libgodot_math_tex.android.release.arm64.so`
（库名**必须 `lib` 开头**，否则 Godot 安卓导出会报错。）

导出 debug APK 时 `.gdextension` 会找 `android.arm64.debug`；若无严格 debug 需求，可复制 Release 产物：
```powershell
Copy-Item gdextension/bin/libgodot_math_tex.android.release.arm64.so `
          gdextension/bin/libgodot_math_tex.android.debug.arm64.so
```

### 8.3 生成运行时资源包（仅当 `gdextension/res/` 有改动时）

```powershell
& "<godot441.exe>" --headless --path . --script res://tools/pack_math_res.gd
# 生成 gdextension/res.bin（已入库，通常无需重跑）
```

## 11. 已知坑与注意

- **Error 126（Windows 加载扩展失败）**：Godot 4.4 用 `LOAD_LIBRARY_SEARCH_DEFAULT_DIRS` 加载扩展，MinGW 依赖 DLL 即使同目录也找不到。解法：全静态链接（`-static -static-libgcc -static-libstdc++` + 显式 `.a` 归档），成品 DLL 仅依赖系统 DLL。
- **Android 库名前缀**：原生库必须以 `lib` 开头（`libgodot_math_tex...so`）。
- **`.gdignore` 会整目录跳过**：放在 `gdextension/res/.gdignore` 后，导出连 `include_filter` 也救不回该目录；因此运行时资源不走目录，而是打成 **`res.bin`** 再用 `include_filter` 打入包。
- **`*.zip` 不被打包**：`all_resources` 不会把 `.zip` 打进包，故资源包用 `.bin` 扩展名。
- **中文路径 / `user://`**：MicroTeX/FreeType 在 Windows 用 ANSI 窄路径，`user://` 落在含中文工程名目录会失败。运行时改为把 `res.bin` 解压到 **OS 临时目录（ASCII）** 再 `configure()`。
- **渲染缓存版本**：`InlineMath.MT_CACHE_VERSION`（当前 `v2`）。改动后端排版后需 +1，旧 `user://mt_cache/*.mttex` 才会失效。
- **PowerShell 二进制重定向**：`>` 会破坏 `adb exec-out screencap` 等二进制输出；请用 `adb shell ... /sdcard/x` 再 `adb pull`，或 `cmd /c`。
- **小米/MIUI input 注入**：`adb shell input tap` 会被拒（需「USB 调试(安全设置)」）。
- **GitHub 访问**：若被屏蔽，godot-cpp/MicroTeX/模板的下载需走代理或镜像；MSYS2 pacman 可切国内镜像。
- **全局类缓存（换机首次打开必做）**：新增 `class_name`（如 `BossHud`）后，若 `.godot/global_script_class_cache.cfg`
  里没有该条目，会连锁报 `Parse Error: Could not find type "BossHud"`（连带 `StageBase.gd` 等解析失败）。
  解法：用编辑器打开项目一次，或跑 `& "<godot472.exe>" --headless --editor --path . --quit` 生成缓存。
- **Godot 4.7.2 无 console 变体**：无头运行时直接连控制台会丢输出，需
  `Start-Process -Wait -RedirectStandardOutput/RedirectStandardError` 重定向后再读文件。
- **不入库**：`third_party/`、`godot-cpp/`、`gdextension/bin/`、`gdextension/build*/`、`build/`、`*.apk/*.pck/*.log`、生成的 `*.dll/*.so`。

## 12. 快速复现顺序（TL;DR）

1. 装 MSYS2（gcc/cmake/ninja/pkgconf/freetype/harfbuzz/tinyxml2）。
2. 装 Godot 4.4.1 与 4.7.2，并为 4.7.2 安装导出模板。
3. 装 Android SDK / JDK17 / NDK 23.2.8568313。
4. `git clone` 本仓库；在 `third_party/` 放 godot-cpp(4.4) 与 MicroTeX，并准备 `android_deps/install/arm64`。
5. 构建 Windows Debug 扩展；需要安卓时构建 arm64 Release 扩展。
6. 配置 Godot 编辑器 Android SDK/JDK/keystore。
7. 用 4.7.2 导出 `build/衍数阁.apk`，`adb install` 验证。
8. 跑第 10 节的回归命令确认环境正确。
