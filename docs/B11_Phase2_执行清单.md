**补强方案**（新增 2 道多步探究题）:

#### Sequence_FixedPoint_Method
- **题型**: input
- **场景**: "已知 a₁=1, a_{n+1}=2a_n+1，用特征根法求通项"
- **步骤**: ①求特征根 → ②构造等比数列 → ③写出通项
- **explain 指引**: "先解方程 r = 2r+1 得到特征根 r=-1"

#### Sequence_Telescoping_Sum
- **题型**: input
- **场景**: "求 Σ[1/(n(n+1))] 的前 n 项和（裂项相消）"
- **步骤**: ①拆项 → ②列出前几项 → ③观察抵消规律 → ④得出公式
- **explain 指引**: "1/[n(n+1)] = 1/n - 1/(n+1)，展开后中间项会抵消"

   - 必须有滑动条、拖拽、实时反馈
   - explain 中必须包含"拖动...观察..."的操作指引

3. **方法覆盖准确**: 新增题目要对应具体缺失方法
   - 不要重复已有的方法
   - 确保 keyword 能正确触发 detect_methods_in_chapter()
