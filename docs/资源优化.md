## 已落地的机制

1. **源文件不入库**：`.xcf` 等 GIMP/PS 源文件统一放 `assets_src/`（`.gitignore` 已排除）。
   需要留档请另用外部存储 / Git LFS —— 仓库里只保留运行时导出图。
2. **导出排除**：`export_presets.cfg` 的四个预设 `exclude_filter` 已加 `assets_src/*, *.xcf`。
3. **降采样工具**：
   ```powershell
   & "<godot4.7.2.exe>" --headless --path . --script res://tools/optimize_art.gd              # 预览
   & "<godot4.7.2.exe>" --headless --path . --script res://tools/optimize_art.gd -- --apply    # 写回
   ```
   规则：`res://icon.png` → ≤512；`res://art/**/*.png` → 最长边 ≤2048（防未来误入超大图）。
   只做等比降采样，不做有损转换。
4. **入库/体积护栏**（可进 CI）：
   ```powershell
   & "<godot4.7.2.exe>" --headless --path . --script res://tools/check_assets.gd
   ```
   违规（源文件入库 / 超硬预算 40MB）退出码 1；>22MB 仅告警。
   CI：`.github/workflows/check.yml` 的 `check_assets` 步骤。

## 残留（需决策/换机执行）

1. **标题字体 `art/fonts/aidianqianfengxingshu.ttf`（13.5 MB）**——最大单文件，且授权不可核实（见 F7）。
   **换成 OFL 字体（如霞鹜文楷/得意黑）后，仓库可降到约 20 MB 以内**，同时解决 F7。
   替换方式：删旧 `.ttf`、放入新 `.ttf/.otf`（`scripts/ui/UI.gd` 自动加载 `art/fonts/` 下任意字体）。
2. **两张 1080p 背景**（`art/bg_worldmap.png` 4.9 MB、`art/bg_mainhub.png` 2.3 MB）未压缩。
   本机没有 `pngquant`/`cwebp`/ImageMagick，无法在此完成；可在有工具的环境执行：
   ```
   pngquant --quality=80-95 --force --ext .png art/bg_*.png
   ```
   或用 Godot 导入设置把背景的 `compress/mode` 改为 VRAM 压缩（`2`）/ 有损。
   **改后必须目视比对首页/知识体系/关卡内观感**（本项属「观感」验收，需人工确认）。
3. **APK 体积重新基线**：需在有 Android SDK 的环境重新导出 release APK 并记录新基线
   （治理前 debug APK 60.9 MB，已减掉 `.xcf` 与 GPLv3 字体，预期明显下降）。
