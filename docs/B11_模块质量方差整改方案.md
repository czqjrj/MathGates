## 二、「深度」量化指标定义

### 2.1 核心公式

```
depth_score = 0.30 × formula_density + 
              0.25 × steps_per_question + 
              0.20 × explain_coverage + 
              0.15 × question_length_norm + 
              0.10 × non_pick_ratio
```

### 2.2 各项指标说明

| 指标 | 权重 | 计算方式 | 教育测量意义 | 归一化方法 |
|------|-----:|----------|--------------|-----------|
| **公式密度** | 30% | Σ(公式数) / Σ(题目数) | 数学思维的抽象程度与符号化能力 | min(value/3.0, 1.0) |
| **平均步骤** | 25% | Σ(步骤数) / Σ(题目数) | 解题过程的复杂程度与思维链条长度 | min(value/3.0, 1.0) |
| **解析覆盖率** | 20% | 有解释的题目数 / 总题数 | 诊断性反馈的质量，帮助学生理解错因 | 直接使用 (0-1) |
| **题干长度** | 15% | Σ(题干字符数) / Σ(题目数) | 问题表述的完整度与信息量 | min(value/100.0, 1.0) |
| **非选择题比** | 10% | (总题数 - 四选一题数) / 总题数 | 开放型题目占比，反映探究性 | 直接使用 (0-1) |

### 2.3 权重设计依据

权重参考教育测量理论中的「认知复杂度维度」：

1. **公式密度 (30%)**：最高权重。数学学科的核心特征是符号化表达，公式密度直接反映题目的抽象思维要求。
2. **平均步骤 (25%)**：次高权重。多步推理是区分浅层记忆与深层理解的关键。
3. **解析覆盖率 (20%)**：诊断性反馈对学习效果影响显著（Hattie 效应量 d=0.90）。
4. **题干长度 (15%)**：完整的问题情境描述有助于培养建模能力。
5. **非选择题比 (10%)**：开放型题目促进创造性思维，但不宜过高以免失去可测性。

## 四、验收标准

### 4.1 整体指标

- **方差收敛**：深度标准差从 0.069 降至 **≤ 0.05**（方差 ≤ 0.0025）
- **最低门槛**：所有章节深度分 ≥ **0.45**
- **平均值提升**：从 0.505 提升至 **≥ 0.52**

### 4.2 过程指标

每次整改后运行 `tools/analyze_depth.py` 检查：

```bash
godot --headless --path . --script res://tools/analyze_depth.py
```

预期输出应显示：
- 无章节 depth_score < 0.45
- 标准差 ≤ 0.05
- 整改前后的对比数据表

### 4.3 反向验证

临时删掉某个章节的一道多步题 → 重新运行分析 → 该章节的 steps_per_q 和 depth_score 应下降；恢复后复升。

## 六、附录：工具使用说明

### 6.1 深度分析工具

```bash
python tools\analyze_depth.py
```

输出包含：
1. 各章节深度评分表（按分数排序）
2. 各项指标的详细数值
3. 整改建议清单

### 6.2 单项指标计算方法

以公式密度为例，在 GDScript 中可以这样实现：

```gdscript
func count_formula(text: String) -> int:
    if text.is_empty():
        return 0
    var count := 0
    count += text.count("$$") / 2  # LaTeX 美元定界符
    count += text.count("\\frac")   # 分数
    count += text.count("^") + text.count("{^")  # 幂
    # Unicode 数学符号（可根据需要扩展）
    for c in ["²", "³", "α", "β", "γ", "π", "Σ", "Δ"]:
        if c in text:
            count += 1
    return count
```
