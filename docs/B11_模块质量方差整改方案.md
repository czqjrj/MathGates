## 一、现状（2026-11-03 第二次实测，口径已校准）

### 1.1 口径修正说明

本轮修复了 `tools/analyze_depth.py` 的三处口径缺陷：

1. **章节覆盖面**：旧版按 `data/<id>_levels.json` 硬拼路径，27 章中仅命中 22 章（`line_eq/circle_eq/recurrence_methods/function_methods/solid` 五个章节被静默跳过）。现通过课程表的 `lab+lab_ref/sequence/conic/method` 指针正确取数，27 章全覆盖。

2. **题型判定**：旧版只认 `type="pick"` 为选择题，但全库 `type` 有 5 种写法（缺省 133 轮、`choice` 413 轮、`pick` 6 轮、`input`、`interact`）。413 轮 `choice` 被误判为非选择，导致「非选%」对 20/24 章都是错的。现与 `check_questions.gd` 使用同一套判定（有非空 opts 即选择，ans 为数组为多选），explore 轮收尾同样是四选一，按选择题计。

3. **字段是否真的显示**：`explain/steps` 只有 StageBase 系场景（LabStage/Lab3DStage/SequenceStage）会渲染；ConicStage 与 SolidChallenge 不读这两项——在这些章节补解析，学生永远看不到，分数却会涨，属于假指标。现按场景把「可测轮次」圈出来，`solid`（全不测）标 `n/a` 并排除在方差统计外。

### 1.3 主要发现

1. **vector 章符号化收益巨大**：41 条题干从纯文本向量记号改为 `$$\vec{a}$$` 后，公式密度从 0.12→2.62，深度分从 0.337→0.626。这说明「公式密度」这一维对「是否用 LaTeX 写」极度敏感；**不应把 0.626 解读为内容变深**，而是符号呈现统一（A10 延伸）带来的自然收益。

2. **最薄章节是 statistics (0.288)**：32 题，公式密度 0.06，步骤 0。统计类题目多是概念/流程描述，天然符号密度低，且无 explore 轮步骤。按当前权重体系，该章的理论上限约 0.58（即使公式≥3）。

## 二、「深度」量化指标定义

### 2.1 核心公式

```
depth_score = 0.30 × formula_density + 
              0.25 × steps_per_question + 
              0.20 × explain_coverage + 
              0.15 × question_length_norm + 
              0.10 × non_pick_ratio
```

### 2.2 各项指标说明

| 指标 | 权重 | 计算方式 | 教育测量意义 | 归一化方法 |
|------|-----:|----------|--------------|-----------|
| **公式密度** | 30% | Σ(公式数) / Σ(题目数) | 数学思维的抽象程度与符号化能力 | min(value/3.0, 1.0) |
| **平均步骤** | 25% | Σ(步骤数) / 可测轮次 | 解题过程的复杂程度与思维链条长度 | min(value/3.0, 1.0) |
| **解析覆盖率** | 20% | 有 explain 的可测轮次 / 可测轮次 | 诊断性反馈的质量，帮助学生理解错因 | 直接使用 (0-1) |
| **题干长度** | 15% | Σ(题干字符数) / Σ(题目数) | 问题表述的完整度与信息量 | min(value/100.0, 1.0) |
| **非选择题比** | 10% | (总题数 - 四选一题数) / 总题数 | 开放型题目占比，反映探究性 | 直接使用 (0-1) |

### 2.3 权重设计依据

权重参考教育测量理论中的「认知复杂度维度」：

1. **公式密度 (30%)**：最高权重。数学学科的核心特征是符号化表达，公式密度直接反映题目的抽象思维要求。
2. **平均步骤 (25%)**：次高权重。多步推理是区分浅层记忆与深层理解的关键。
3. **解析覆盖率 (20%)**：诊断性反馈对学习效果影响显著（Hattie 效应量 d=0.90）。
4. **题干长度 (15%)**：完整的问题情境描述有助于培养建模能力。
5. **非选择题比 (10%)**：开放型题目促进创造性思维，但不宜过高以免失去可测性。

## 四、验收标准

### 4.1 整体指标

- **方差收敛**：深度标准差从 0.080 降至 **≤ 0.05**（方差 ≤ 0.0025）
- **最低门槛**：所有章节深度分 ≥ **0.45**
- **平均值提升**：从 0.467 提升至 **≥ 0.52**

### 4.2 过程指标

每次整改后运行 `tools/analyze_depth.py` 检查：

```bash
python tools\analyze_depth.py
```

预期输出应显示：
- 无章节 depth_score < 0.45
- 标准差 ≤ 0.05
- 整改前后的对比数据表

### 4.3 反向验证

临时删掉某个章节的一道多步题 → 重新运行分析 → 该章节的 steps_per_q 和 depth_score 应下降；恢复后复升。

## 六、附录：工具使用说明

### 6.1 深度分析工具

```bash
python tools\analyze_depth.py          # 打印表格
python tools\analyze_depth.py --json   # JSON 输出，便于二次处理
```

输出包含：

2. 各项指标的详细数值
3. 整改建议清单
4. 被排除章节（不适用）列表

### 6.2 公式计数规则

以公式密度为例，工具内实现：

```python
def count_formula(text):
    if not text:
        return 0
    s = str(text)
    latex_dollar = s.count('$$') // 2
    latex_frac = s.count('\\frac')
    latex_power = s.count('^') + s.count('{^')
    unicode_math = sum(1 for c in s if c in '²³αβγδθλμπΣΔ')
    return latex_dollar + latex_frac + latex_power + unicode_math
```
