## 🎮 **测试步骤**

### 方案 A：临时集成测试（推荐首次测试）

**目标**：验证 JSON 能否被 GameData 正确加载并渲染场景

1. **打开 Godot 编辑器**
   ```powershell
   # 在项目根目录运行
   godot --path E:\MathGates-main
   ```

2. **检查数据结构加载**
   - 运行项目后，进入「主城」（MainHub）
   - 打开「档案库」或「学习报告」查看是否有新章节入口
   - 如果没有入口，说明还未集成到 curriculum.json

3. **临时添加课程表入口（快速测试）**
   
   编辑 `data/curriculum.json`，在末尾添加一个测试章节：
   
   ```json
   {
     "id": "circle_param_test",
     "kind": "lab",
     "title": "【测试】参数调参师·圆的方程",
     "subtitle": "Debug 模式 · 仅供测试",
     "color": "#9C27B0",
     "levels": [
       {
         "id": "circle_pm_1",
         "name": "PM-CIRCLE_1-1",
         "technique": "拖动滑块调出圆心和半径",
         "archetype": "SLIDER",
         "sequence": "circle_pm_1",
         "scene": "res://scenes/LabStage.tscn"
       }
     ]
   }
   ```

4. **验证数据加载**
   - 保存 curriculum.json
   - 重新运行项目
   - 在主城查看是否出现「【测试】参数调参师·圆的方程」章节
   - 点击进入该关卡

5. **测试交互**
   - **滑动滑块**：拖动 a、b、r 三个滑块
   - **观察实时变化**：圆的圆心位置和半径应实时变化
   - **检查读数**：右上方应该显示当前 a、b、r 的值和「a≈-1?」「b≈1?」「r≈2.6?」的 ✓标记
   - **点击确认**：当参数接近目标值时，点击「参数已经调到目标值」按钮
   - **验证 gate**：如果误差在容差范围内（a±0.15, b±0.15, r±0.23），应该显示追问问题；否则显示 retry 提示
   - **回答追问**：选择答案后查看 success/explain 文案

### 方案 B：使用校验器静态分析（不启动 Godot）

**目标**：在不运行项目的情况下验证数据格式和结构完整性

1. **运行内容校验器**
   ```powershell
   # 在 Godot 控制台中运行
   godot --path E:\MathGates-main --script scripts/tools/check_questions.gd
   ```

2. **关注输出中的错误类型**
   - `STRUCTURE_ERROR` - 结构错误
   - `SCENE_MISSING` - 场景文件缺失
   - `ANS_RANGE` - 答案范围越界
   - `DUPLICATE_ID` - ID 重复
   - `GATE_CHECK` - gate 验证失败

## ⚠️ **常见问题排查**

### Q1: 章节未出现在主城
**原因**：curriculum.json 未包含新的章节 ID  
**解决**：手动添加章节入口（见方案 A 步骤 3）

### Q2: 关卡显示空白或崩溃
**可能原因**：
- scene 字段指定的 `.tscn` 文件不存在
- LabStage.gd 脚本未正确绑定
- JSON 语法错误

**排查**：
```bash
# 检查场景文件是否存在
ls scenes/LabStage.tscn
ls scripts/modules/lab/LabStage.gd

# 运行 Godot 控制台查看详细报错
godot --path E:\MathGates-main --check-only
```

### Q3: 滑块无法拖动
**原因**：`LabPlane.begin_sliders()` 未被正确调用  
**排查**：
- 检查关卡数据的 `type` 是否为 `"explore"`
- 检查 `scene.sliders` 数组是否非空
- 查看 Godot 控制台的运行时日志

### Q4: gate 验证总是失败
**原因**：容差设置过小或目标值偏差过大  
**调整**：修改 `tol` 字典，例如：
```json
"tol": {"a": 0.3, "b": 0.3, "r": 0.5}
```

### Q5: 读数表达式不更新
**原因**：`readouts.expr` 使用了 Godot 不支持的函数名  
**修复**：将表达式改为基本的算术运算，如：
- ❌ `calc_max(f,a,b)` - 不支持
- ✅ `abs(a+1)<0.15` - 支持
