## 🎮 参数调参师设计要点

### 核心玩法
学生通过拖动滑块调整参数，实时观察图像/读数变化，找到满足特定条件的参数范围。

### 关键特性
1. **多目标条件**：每关有 2-3 个明确目标（如「三个零点」「单调递增」「极大值 > 0」）
2. **实时反馈**：通过 `readouts` 显示当前参数是否接近目标
3. **容差验证**：使用 `gate` + `answers` + `tol` 机制判定成功
4. **追问闭环**：成功后弹出概念性问题巩固知识

### 数据格式示例

```json
{
  "name": "PM-1 调出三个零点",
  "type": "explore",
  "goal": "拖动 a、b 两个滑块，让 f(x) = x(x-a)(x-b) 的三个零点分别为 0、1、2",
  "q": "...",
  "steps": ["① ...", "② ...", "③ ..."],
  "tip": "...",
  "confirm": "我找到了正确的参数组合",
  "gate": true,
  "answers": {"a": 1, "b": 2},
  "tol": {"a": 0.15, "b": 0.15},
  "retry": "零点位置还不对...",
  "ask": "多项式有三个不同零点的条件是？",
  "opts": [...],
  "ans": 0,
  "hint": "...",
  "explain": "...",
  "success": "太棒了！",
  "scene": {
    "sliders": [
      {"name": "a", "min": -0.5, "max": 3, "value": 1.0, "step": 0.1, "label": "第二个根 a"},
      {"name": "b", "min": -0.5, "max": 3, "value": 2.0, "step": 0.1, "label": "第三个根 b"}
    ],
    "curves": [{"fn": "cubic_factorized", "roots": [0, "a", "b"], "color": "#9C27B0"}],
    "lines": [
      {"x": 0, "dash": true, "label": "x=0"},
      {"x": 1, "dash": true, "label": "x=1"},
      {"x": 2, "dash": true, "label": "x=2"}
    ],
    "readouts": [
      {"label": "a≈1?", "expr": "abs(a-1)<0.15", "color": "#4caf50"},
      {"label": "b≈2?", "expr": "abs(b-2)<0.15", "color": "#4caf50"}
    ]
  }
}
```
