把用豆包生成的图片放到这个目录里,按下面对应文件名命名即可自动生效(无需改代码)。

支持格式: .png / .webp / .jpg  (需要透明的件请用 png 或 webp)

文件名对照表:
  bg_mainhub.png            主城背景          1920 x 1080   不透明
  bg_worldmap.png           世界地图背景       1920 x 1080   不透明
  island_unlocked.png       章节浮岛·已解锁    512 x 512     透明
  island_locked.png         章节浮岛·锁定      512 x 512     透明
  ui_panel.png              通用面板框(9-patch)  透明
  ui_button.png             按钮 9-patch        透明
  ui_button_hover.png       按钮·悬停(可选)     透明
  ui_button_pressed.png     按钮·按下(可选)     透明
  ui_button_disabled.png    按钮·禁用(可选)     透明
  icon_star_full.png        满星               256 x 256     透明
  icon_star_empty.png       空星               256 x 256     透明
  icon_map.png              主城·冒险之门       256 x 256     透明
  icon_tree.png             主城·技能树         256 x 256     透明
  icon_book.png             主城·图鉴           256 x 256     透明
  icon_train.png            主城·训练场         256 x 256     透明

9-patch 边框宽度可在 scripts/Art.gd 里调 PATCH_BUTTON / PATCH_PANEL。

先做 3 张验证风格: bg_mainhub、ui_panel、island_unlocked。
